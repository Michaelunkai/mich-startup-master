**Identity Statement**: Unified design system for cross-platform native application with emphasis on readability, accessibility, and visual hierarchy.

**Unbreakable Rules**:
1. **One Accent**: Single accent color for all UI elements
2. **Mono for Machine Values**: Monospace font for code-like data display
3. **No Decorative Noise**: All non-functional decorative elements must serve informational purpose
